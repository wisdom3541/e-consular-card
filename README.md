# E-consular Card

Digital consular services platform for seamless access to consular card management.

## Features

- ✅ NIN Verification & Registration
- ✅ OTP-based Authentication
- ✅ Card Request & Payment Processing
- ✅ Digital Signature Management
- ✅ Payment History & Tracking
- ✅ Support Ticket System

## Getting Started

### Prerequisites

- Flutter SDK (>=3.0.0)
- Dart SDK
- Android Studio / Xcode (for mobile development)

### Installation

1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/e-consular-card.git
cd e-consular-card
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the app
```bash
flutter run
```


## Tech Stack

- **Framework:** Flutter
- **State Management:** Provider
- **HTTP Client:** Dio
- **UI:** Material Design 3
- **Payment:** GlobalPay Integration
